# Archived native iOS experiment

The separate Swift wallet was retired on 2026-10-27. There is no application to
build here. Its custom portfolio, history, balance SDK bindings, sample data,
loopback server and old target were removed. The only active application is
[OISY Capacitor](../capacitor/README.md).

Earlier research, screenshots and machine-specific test logs may remain under
an ignored local `docs/` directory. They are deliberately excluded from review
commits and do not describe current capabilities. The original dated spec retains
the design decisions; the current app owns authentication and Explore.
